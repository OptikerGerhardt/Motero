# Motero 1.1.5 / Build 331

- Both docks share `ReaderToolDockLayout`: Undo, the existing tool set and options determine the shell, with a separate Redo slot only when it fits. PDF uses 344/392 dp and EPUB 248/296 dp, bounded by actual available width. The tool row fills its 60-dp frame and centers its 48-dp controls. Palette/size rows share the content width; small docks scroll colors and compress the slider. Transition content stays within its target width, and Redo waits until that width is available.
- Bookmark flags move farther inward. The viewport hint uses status/cutout insets even when bars are hidden, plus a safe initial status-bar fallback. Partially obscured physical-page flags are hidden while replaced by the centered page's viewport hint; normal notes and saved geometry remain unchanged. The original upper-right shortcut also includes the inset hint on short landscape screens. Lower page-turn regions remain separate.
- Opening/closing the creation dock explicitly restores the native and web pointer tool. Pen hold-and-drag highlighting can run with chrome visible; selecting a drawing tool remains explicit. Existing pen/palm and eraser behavior is retained.
- Highlight/underline popup colors and Quick Tags precede the five-line comment editor. Quote height derives from the actual dialog bounds, not just the full screen; the vertical quote rule tracks the selected highlight color. Configured library tags and existing editability rules are reused, without inventing tag assignments. Tablet search icons reflect actual search state.
- The tablet sidebar changes the document width once, then animates placement with graphics-layer translation. It keeps the PDF beside the sidebar and avoids frame-by-frame WebView reflow. The Reader's layout branch is saved across rotation so available-dp changes do not destroy/recreate its renderer subtree. These changes remove avoidable work; no measured physical-device rotation speedup is claimed.
- Sidebar selection and direct Jump use the cropped-page controller before centering the annotation. Oversized pages retain valid scroll limits and column ownership. Requests are serialized, superseded targets stop positioning, and failed page entry cannot pan another page. Direct Jump waits for the native pane resize and stable web viewport; repeated selection can return to the same annotation without closing the sidebar.

Regression tests cover open-chrome pen highlighting, safe flag geometry and hit regions, cropped Jumped selection, pane-resize focus and rapid navigation. Native geometry tests cover PDF/EPUB widths and Redo thresholds. Physical tablet/BOOX visual transitions and rotation timing are not available here; they still need device confirmation. Live-account sync is separate. PDF.js, runtime pins and annotation/sync formats remain unchanged. [Evidence](../qa/build331/README.md).

The next-page viewport arrow is 72 dp with 40% opacity, isolated above PDF highlights and below the magnifier/quick palette. It remains passive and uses the same safe top inset; its actual browser paint order is checked against a PDF highlight.

Verification: 443 Reader cases, 167 native cases, all 23 local and CI browser suites, 43 engine pixel cases and 19 official viewer cases pass.
