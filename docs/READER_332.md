# Motero 1.1.6 / Build 332

- Highlight/underline popups use the existing Zotero divider between Quick Tags and the comment editor.
- Document selections clear stale sidebar destinations and honor `centerInDocument=false`. A native regression exercises a document selection following a sidebar selection. Long holds keep their quickbar; delayed neighboring crop-layout updates compare the annotation's actual screen rectangle rather than raw scroll offsets. Actual document movement still dismisses the quickbar, and handle dragging hides/restores it as before.
- A passive oval briefly identifies a complete visible word below the previous reading edge, or the first visible word on a new page. It uses the existing PDF text geometry, active crop/column visibility and page transform. It never moves content or stores annotations, adds no canvas and has no animation frame loop. The oval fades over 1.1 seconds; E-Reader/reduced-motion mode uses a static temporary oval. Rapid scrolling, page replacement, zoom, manual crop and document teardown cancel stale work. Textless scans receive no guessed word marker.
- The next-page arrow is removed from the active code. Its implementation and tests remain in Git history at the [Build 331 Reader commit](https://github.com/OptikerGerhardt/Motero/blob/7c3e4780e5c368ae4f10ac169d9f505be03eedb2/src/pdf/viewport-indicators.js), referenced by the existing v1.1.5-331 release. No unused archive copy or runtime toggle is added.
